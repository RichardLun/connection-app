# connection-app

The name is still to be decided.

A web app that helps youth group leaders see whether the kids in their group are connecting. At the end of a session, each kid checks in on the leader's device. The leader then sees who connected with whom, and who might need help. Data is saved to a Supabase database.

The guides are in `docs/`. Read them in this order:

1. [docs/onboarding.md](docs/onboarding.md): getting set up
2. [docs/outline.md](docs/outline.md): what we're building, and how we'll work
3. [docs/build-steps.md](docs/build-steps.md): the step-by-step build

## Running it

```
npm run dev    # run the app on your computer
npm test       # run the tests
```

Every branch you push gets a preview link from Vercel, which shows up on its pull request.
