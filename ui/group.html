Group

This screen gets built in Step 12 of docs/frontend-steps.md.

On this page

  1. Scroll down to Kids to add kids to the group, one name at a time. Two kids can't share a name, so add a last initial if you need to, like "Sam P.".
  2. To start a session, pick the date and activity, and add a note if you like. Sessions are numbered for you: Session 1, Session 2, and so on.
  3. Click Start session and the new session opens straight away. You've created your first session! Kick it off by ticking who's here.
  4. Every session is listed under Sessions, newest first. Click one to open it again.
  5. Once you have two or more sessions, Compare sessions shows what changed.

Fixing the kids list

  • Edit fixes a kid's name.
  • Remove only shows for kids who aren't in any session yet: not ticked as here, not checked in, and not picked by another kid. That way, removing a kid never deletes anyone's check-in.
