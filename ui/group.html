On this page

  1. How this group uses Connected shows the choices you made for this group. You can switch to group-only reports at any time, but leader support can only be added before any kid checks in.
  2. Scroll down to Kids to add kids to the group, one name at a time. Two kids can't share a name, so add a last initial if you need to, like "Sam P.". Groups that don't use names have no kids list.
  3. To start a session, pick the date and activity, and add a note if you like. You can also add an activity goal (what kids should be able to do afterwards) and a learning question to ask at check-in. Both are optional.
  4. Choose when kids check in and which questions to ask. Each question is labelled with what it asks: interaction, belonging, learning, activity feedback or context. For a group that meets regularly, keep the same questions and timing each time, so sessions can be compared.
  5. Click Start session and the new session opens straight away. You've created your first session! Kick it off by ticking who's here. A single activity has just one check-in, so you set it up once.
  6. Every session is listed under Sessions, newest first. Click one to open it again.
  7. Once a regular group has two or more sessions, Compare sessions shows what changed.

Fixing the kids list

  • Edit fixes a kid's name.
  • Remove only shows for kids who aren't in any session yet: not ticked as here, not checked in, and not picked by another kid. That way, removing a kid never deletes anyone's check-in.
